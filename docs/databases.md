# Database Schemas

## Traffic Service — SQLite3 (traffic.db)

```sql
CREATE TABLE IF NOT EXISTS traffic (
  id TEXT PRIMARY KEY,
  city TEXT NOT NULL,
  zone TEXT NOT NULL,
  status TEXT NOT NULL DEFAULT 'FREE',
  congestion_level INTEGER NOT NULL DEFAULT 0,
  road_condition TEXT NOT NULL DEFAULT 'NORMAL',
  updated_at TEXT NOT NULL
);
```

Valid `status`: FREE, MODERATE, CONGESTED, BLOCKED
Valid `road_condition`: NORMAL, DANGEROUS, WET
`congestion_level`: 0–100

## Incident Service — SQLite3 (incident.db)

```sql
CREATE TABLE IF NOT EXISTS incidents (
  id TEXT PRIMARY KEY,
  city TEXT NOT NULL,
  zone TEXT NOT NULL,
  type TEXT NOT NULL DEFAULT 'ACCIDENT',
  severity TEXT NOT NULL DEFAULT 'MEDIUM',
  description TEXT,
  status TEXT NOT NULL DEFAULT 'ACTIVE',
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
```

Valid `type`: ACCIDENT, EMERGENCY, ROAD_BLOCKED, WEATHER_ALERT
Valid `severity`: LOW, MEDIUM, HIGH, CRITICAL
Valid `status`: ACTIVE, RESOLVED

## Weather Service — SQLite3 (weather.db)

```sql
CREATE TABLE IF NOT EXISTS weather (
  id TEXT PRIMARY KEY,
  city TEXT NOT NULL,
  temperature REAL NOT NULL DEFAULT 20.0,
  wind_speed REAL NOT NULL DEFAULT 0.0,
  rainfall REAL NOT NULL DEFAULT 0.0,
  condition TEXT NOT NULL DEFAULT 'CLEAR',
  is_dangerous INTEGER NOT NULL DEFAULT 0,
  updated_at TEXT NOT NULL
);
```

Valid `condition`: CLEAR, CLOUDY, RAIN, STORM, FOG, SNOW
`is_dangerous`: stored as INTEGER (0/1), returned as boolean via rowToWeather()

Danger conditions:
- wind_speed > 80
- rainfall > 50
- condition = 'STORM'
- condition = 'FOG'

## Parking Service — RxDB (in-memory)

Schema:
```json
{
  "version": 0,
  "primaryKey": "id",
  "type": "object",
  "properties": {
    "id":               { "type": "string", "maxLength": 100 },
    "name":             { "type": "string" },
    "city":             { "type": "string" },
    "zone":             { "type": "string" },
    "total_spots":      { "type": "integer" },
    "available_spots":  { "type": "integer" },
    "is_full":          { "type": "boolean" },
    "updated_at":       { "type": "string" }
  },
  "required": ["id", "name", "city", "zone", "total_spots", "available_spots"]
}
```

Note: in-memory storage resets on service restart.

## Notification Service — RxDB (in-memory)

Schema:
```json
{
  "version": 0,
  "primaryKey": "id",
  "type": "object",
  "properties": {
    "id":           { "type": "string", "maxLength": 100 },
    "city":         { "type": "string" },
    "type":         { "type": "string" },
    "title":        { "type": "string" },
    "message":      { "type": "string" },
    "source_event": { "type": "string" },
    "created_at":   { "type": "string" }
  },
  "required": ["id", "city", "type", "title", "message", "source_event", "created_at"]
}
```

Note: in-memory storage resets on service restart. Notifications are repopulated from Kafka as new events arrive.

## ID Format

All IDs are UUID v4, generated by the `uuid` package at creation time.
